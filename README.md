# 🌸 我的股票本 - 粉色治愈系安卓APP使用指南

> 这是一款**温柔治愈风的股票手账本 PWA**（渐进式Web应用），无需安装 Node.js/Android Studio，**所有股票由你亲手添加**，隐私100%安全。部署后在安卓手机一键安装到桌面，和原生APP体验一模一样。

| 模块 | 说明 |

## 🚀 方法一：5秒快速本地试用（电脑端）

### 1. 打开文件
直接双击 `StockWorkbench/index.html` 用浏览器打开即可。
> ⚠️ 本地 `file://` 打开时 PWA 安装功能不生效，行情接口可能受浏览器CORS限制（会自动用模拟数据替代）。

### 2. 推荐：用 Python 或任意静态服务器预览
如果电脑装了 Python，在 `StockWorkbench/` 目录打开命令行：
```bash
# Python 3
python -m http.server 8080
```
然后浏览器访问：`http://localhost:8080`
> 这样 PWA 功能和行情接口都能正常工作。

## 📲 方法二：安装到安卓手机（作为原生APP使用）

### 前置准备：把整个文件夹部署到任意静态托管

PWA 必须通过 HTTPS（或 localhost）访问才能安装。任选其一：

| 方案 | 难度 | 说明 |
|------|------|------|
| **GitHub Pages** | ⭐ | 免费，推代码自动部署，推荐 |
| **Vercel / Netlify** | ⭐ | 拖拽上传文件夹，10秒上线 |
| **Gitee Pages** | ⭐ | 国内访问更快 |
| **Cloudflare Pages** | ⭐⭐ | 全球 CDN 加速 |
| **自己的服务器（Nginx）** | ⭐⭐⭐ | 上传目录后配置静态站点即可 |

### 安卓安装步骤（以 Chrome 浏览器为例）

1. 手机 Chrome 打开部署好的网址（**必须是 HTTPS**）
2. 首次打开会弹出顶部提示条 **「📲 安装到手机桌面，随时查看行情」** → 点「立即安装」
3. 没看到提示？→ 点击浏览器右上角 ⋮ 菜单 → 选择 **「添加到主屏幕」** 或 **「安装应用」**
4. 确认后桌面出现 **「📊 股票工作台」** 图标，点击即可像普通APP一样启动！

## 📖 功能使用说明

### 📋 【自选股】Tab
- 右上角 **➕** → 新增自选股
- **股票代码**：上海=sh开头、深圳=sz开头、北京=bj开头（如 sh600519=贵州茅台，sz000001=平安银行）
- 点 **「根据代码自动填充信息」** → 自动从腾讯接口拉取股票名称
- **持仓数量 / 成本价**：选填，填写后自动计算市值和盈亏
- 点击任意股票卡片 → 查看详情（今开/昨收/最高/最低/换手/PE/成交额等完整信息）

### 🏷️ 【板块】Tab
- 右上角 **「+ 新建板块」** → 自定义板块名称 + emoji 图标 + 主题颜色
- 每个板块展示：股票列表、板块总市值、今日盈亏、仓位占比
- **编辑 / 删除** 板块：卡片右上角按钮

### 📈 【统计】Tab
- **顶部四张总览卡**：总市值 / 今日盈亏 / 总盈亏 / 平均涨幅
- **板块分布**：横向条形图，直观看到每个板块的市值权重和盈亏贡献
- **涨跌榜**：涨幅TOP5 / 跌幅TOP5

### ⚙️ 【设置】Tab
- **自动刷新间隔**：关闭 / 1分钟 / 5分钟 / 10分钟 / 15分钟
- **导出数据**：下载 JSON 备份文件到手机「下载」目录
- **导入数据**：选择备份 JSON 文件，合并导入（同ID覆盖）
- **清空所有数据**：⚠️ 二次确认，重置整个APP

## 🔌 关于行情数据

### 数据源
- 主接口：腾讯财经 `https://qt.gtimg.cn/q=sh600519,sz000001`
- 接口特点：**免费**、**无密钥**、**无调用频率限制**、覆盖全部A股/指数
- 缓存策略：本地缓存 10 分钟，手动点「🔄刷新」强制重新拉取

### 为什么有时显示「示例数据」？
以下情况会自动回落到模拟（Mock）数据：
1. 网络完全断开（仍可离线查看）
2. 公司/学校 Wi-Fi 屏蔽了腾讯接口域名
3. 浏览器 CORS 安全策略拦截（**部署到 HTTPS 站点后，在手机上打开通常无此问题**）
4. 非交易时段接口返回空值

## ❓ 常见问题

**Q: 可以打包成 APK 上传应用商店吗？**
> A: 可以。用 [PWABuilder](https://www.pwabuilder.com/)（微软官方）打开你部署好的网址，点「Package for Android」即可一键生成签名后的 APK/AAB。

**Q: 想加更多功能（K线图、选股提醒、云同步）？**
> A: 目前架构完全可以扩展。云同步推荐接入微信云开发（你之前熟悉的技术栈），只需把 `storage.js` 底层替换成云数据库调用即可。

**Q: iOS 能用吗？**
> A: 完全可以。iPhone 用 Safari 打开 → 下方分享按钮 → 「添加到主屏幕」。

**Q: 如何修改默认板块？**
> A: 打开 `js/storage.js`，找到 `ensureDefaultSectors()` 函数，修改里面的 `defaults` 数组即可。
